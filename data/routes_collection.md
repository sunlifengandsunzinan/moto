### 1. 沈阳·辽阳本溪跑山环线

- **来源博主**：盛京铁骑
- **类型**：1日跑山环线
- **方向**：辽阳进，本溪出
- **总里程**：约 300 km
- **路况**：水泥/沥青，跑山路面
- **可玩性**：三大段纯跑山路段，一整天

**路线分解：**
```
沈阳出发
→ 导航「达荷香」，途经「娃子沟」
→ 沿「汤河水库」骑行
→ 导航「连山关镇」
→ 导航「南天门」
→ 导航「辽燕博物馆」
→ 高速或国道返程
```

**建议：** 辽阳进、本溪出不走回头路，返程走高速或国道自选。适合周末一天。

### 2. 沈阳·抚顺鸦鹘关环线

- **来源博主**：盛京铁骑
- **类型**：短途环线（跑山+人文+湿地）
- **方向**：沈阳→抚顺→返程
- **总里程**：短途
- **路况**：铺装良好，路况友好
- **亮点**：明代关隘 + 水库湿地

**路线分解：**
```
沈阳出发
→ 鸦鹘关（明代古关隘，可露营，山清水秀）
→ 木奇镇（纯跑山路段，弯道多，镇上吃饭休整）
→ 社河湿地公园（沿大伙房水库骑行，视野开阔）
→ 生命之环
→ 沿浑河返程
```

**适合：** 周末一日，地势平缓，路况友好。摩友结伴最佳。

### 3. 新疆·穿越中天山（最推荐）

- **来源博主**：追风少年李二狗
- **类型**：长途探险穿越
- **天数**：约 7 天
- **季节**：5–9 月
- **难度**：⭐⭐⭐⭐⭐（高难度，需运气+体力+技术+勇气）
- **车型**：除巡航车外均可，轻 ADV 更友好
- **导航**：仅能用奥维地图，无常规导航
- **不适合**：新手 ❌（新手优先独库/伊昭公路）

**路线分解（4段）：**
```
① 哈密大海道
② 和静 → 巴音布鲁克（巴和牧道）
③ 巴音布鲁克 → 伊宁（电力天路）
④ 伊宁 → 赛里木湖（伊赛牧道）
```

**行程安排：** 车发物流到哈密 → 穿越结束于赛里木湖 → 经连霍高速回乌鲁木齐 → 再发物流返程。

### 4. 甘肃·深入祁连山腹地（强推）

- **来源博主**：追风少年李二狗
- **类型**：长途探险穿越
- **天数**：约 8 天
- **季节**：5–9 月
- **难度**：⭐⭐⭐⭐
- **路况**：非铺装多，探险感强
- **车型**：ADV 最爽，巡航车不适合 ⚠️
- **加油注意**：部分路段无 95 号油

**亮点：** 颠覆"甘肃=戈壁"的刻板印象，原始森林丰富，保留西北经典景观。

### 5. 川西·非铺装进藏

- **来源博主**：追风少年李二狗
- **类型**：半探险进藏路线
- **天数**：约 7 天
- **季节**：4–10 月（头尾偏冷，6–7 月舒适但车多易堵）
- **路况**：铺装+非铺装，难度不高，路段渐硬化
- **车型**：除巡航车外都适合
- **亮点**：松弛有度，乐趣强于纯公路沿线，可观雪山

### 6. 内蒙·大兴安岭

- **来源博主**：追风少年李二狗
- **类型**：公路长途骑行
- **天数**：约 8 天
- **季节**：6–8 月最佳；9 月可看晚秋；10 月太冷不建议
- **路况**：纯公路，笔直平坦
- **车型**：不挑车，大小排量均可
- **亮点**：森林、火山群，消费低，饮食适配北方人

- **天数**：4–7 天

### 9. 环华·G228→G219→G331 闭环

- **来源博主**：丁小宝（单人单骑）
- **总里程**：中国边境+海岸线完整环线
- **起点/终点**：辽宁丹东东港
- **更新方式**：小号「丁小宝摩旅时况」随拍随发，每晚 19:00 直播

**路线分解（三大段）：**
```
第一段 — G228 沿海国道
  起点丹东东港 → 沿海城市向南 → 徐闻轮渡 → 海南环岛

第二段 — G219 边境国道
  海南出港 → 云南 → 西藏 → 新疆

第三段 — G331 北境国道
  新疆 → 内蒙古 → 黑龙江 → 吉林 → 辽宁
  → 回到辽宁上 G228 骑行约 50 公里到家，完成闭环
```
